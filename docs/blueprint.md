# **App Name**: Scoop Shop

## Core Features:

- Flavor Showcase: Browse a delightful selection of ice cream flavors, each accompanied by mouth-watering images and detailed descriptions.
- Easy Ordering: Customers can effortlessly add desired items to their shopping cart.
- Transparent Delivery Fees: Customers see an accurate, dynamically updated delivery fee displayed clearly at checkout, before they finalize their order.
- Favorite Flavors: The ability to mark your favorite flavors with a heart, so that they may be easily re-ordered again later. Uses localStorage.
- Flavor Recommendations: Generative AI tool recommends complimentary flavors, based on what is already in the user's cart.
- Location Selection: Specify shop location using a pin on a map (latitude/longitude coordinates).

## Style Guidelines:

- Primary color: A creamy, inviting rose-pink (#F7D1CD) evokes the classic flavors of strawberry and raspberry.
- Background color: Soft, desaturated rose-pink (#F9EAE7). Nearly white, allowing content to pop.
- Accent color: A gentle, analogous peach hue (#F7E7D1) that brings warmth and balance. Used to highlight key actions.
- Clean, rounded typography that evokes a feeling of friendliness and approachability.
- Simple, outlined icons with rounded corners, emphasizing a modern, user-friendly interface.
- A grid-based layout that adapts seamlessly across different screen sizes and devices, making it equally accessible for browsing on tablets and phones.
- Subtle transitions and animations, such as flavor cards sliding into view upon page load, enhance user engagement.
