# Crunch Cone 🍦

Modern ice cream parlor web app built with Next.js, Genkit, and Tailwind CSS.

## Features

- **Categorized Menu** – Browse a wide variety of ice cream flavors
- **AI Image Generation** – Generate unique images for any flavor
- **Smart Recommendations** – Get suggestions based on your cart
- **Smooth Checkout** – Easy ordering with owner notifications

## Getting Started

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) to see the app.

Main page lives at `src/app/page.tsx`.
