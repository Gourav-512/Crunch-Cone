# Crunch Cone

Crunch Cone is a modern, AI-enhanced ice cream parlor web application built with Next.js, Genkit, and Tailwind CSS.

## Features

- **Categorized Menu**: Browse a wide variety of ice cream flavors.
- **AI Image Generation**: Generate unique images for any ice cream flavor.
- **Smart Recommendations**: Get flavor suggestions based on your cart.
- **Smooth Checkout**: Easy ordering process with owner notifications.

## Getting Started

To get started, take a look at `src/app/page.tsx`.
